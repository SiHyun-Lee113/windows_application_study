# Windows 네이티브 개발 스터디

Flutter 개발 경험을 바탕으로 C++과 Windows 네이티브 개발을 배우는 스터디 프로젝트다. Codex와 대화하며 개념을 익히고, 직접 코드를 작성·실행하면서 Windows 애플리케이션 개발 역량을 쌓는다.

## 목적

- C++ 문법, 메모리, 객체 수명과 소유권에 대한 이해와 구현 역량을 강화한다.
- 운영체제 기초와 Win32 등 Windows 네이티브 API를 학습한다.
- 빌드, 디버깅, 오류 처리, 테스트를 익히고 작은 Windows 애플리케이션을 완성한다.

## Codex와 함께 하는 것

Codex는 스터디 강사 역할을 맡고, 학습자는 직접 실습하며 이해를 확인한다.

- Flutter와 비교하며 C++ 및 Windows 개념을 설명받는다.
- 실행 가능한 예제와 과제로 기능을 구현하고 결과를 확인한다.
- 코드 리뷰와 피드백을 받고, 오류 원인과 디버깅 방법을 함께 살펴본다.
- 커리큘럼에 따라 수업을 진행하고, 완료한 실습과 남은 과제를 기록한다.

수업은 **학습 목표 → 개념 설명 → 예제 → 직접 실습 → 검증과 피드백** 순서로 진행한다.

표준 C++ 실습은 Windows와 macOS에서 진행하고, Windows 전용 API 실습은 Windows 환경에서 진행한다.
